# Épopée Sport

Sport d'abord, écran ensuite. Cette page bloque tes applis (via Raccourcis sur iPhone ou MacroDroid sur Android) jusqu'à ce que tu fasses ta séance devant la caméra : pompes, abdos, squats, comptés par un squelette IA (MediaPipe Pose), entièrement sur le téléphone.

- `index.html` : l'application
- `pose-logic.js` : le comptage des répétitions et l'anti-triche
- `vendor/` : MediaPipe Tasks Vision 0.10.14 (Apache 2.0)
- `models/pose_landmarker_lite.task` : modèle de pose MediaPipe (Apache 2.0)
